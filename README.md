# Portal Islami Keluarga Mbah Yani
> **"Temani Ibadah Keluarga Setiap Hari"**

Sebuah portal islami modern terintegrasi, responsif, elegan, dan mudah digunakan oleh seluruh anggota keluarga besar Mbah Yani (terutama bagi lansia dan anak-anak).

## ✨ Fitur Utama (Layanan Ibadah Digital)

1. **Jurnal Ibadah (Amal Harian)**  
   Ceklis interaktif untuk memonitor amalan wajib dan sunnah harian secara teratur guna mengistiqomahkan ibadah harian. Dilengkapi dengan *Istiqomah Streak* dan personalisasi nama anggota keluarga.

2. **Al-Qur'an Digital**  
   Akses lengkap 114 surat didukung oleh API resmi Kementerian Agama RI (`equran.id`). Dilengkapi teks Arab, transliterasi Latin, terjemahan Indonesia, dan audio murottal yang dapat dimainkan per-ayat maupun bersambung otomatis.

3. **Cari Arah Kiblat**  
   Menghitung bearing kompas presisi ke Ka'bah di Mekah secara realtime menggunakan koordinat GPS browser. Dilengkapi kompas digital interaktif dan menu preset koordinat keluarga besar di Jawa Timur, Yogyakarta, dan Jakarta.

4. **Tasbih Digital**  
   Counter dzikir masif dan sensitif dengan preset dzikir utama (Subhanallah, Alhamdulillah, Allahu Akbar, Laa Ilaaha Illallah). Mendukung feedback vibrasi (getar HP), suara klik audio, reset mandiri, dan integrasi penyimpanan `localStorage`.

5. **Doa Sehari-hari**  
   Kumpulan untaian doa mustajab sehari-hari (Tidur, Rumah, Makan, Perjalanan, Masjid, dan Keluarga). Dilengkapi teks Arab, Latin, terjemahan Indonesia, serta tombol salin dan konversi instan untuk dikirim langsung ke WhatsApp grup keluarga.

6. **Jadwal Sholat**  
   Waktu shalat fardhu otomatis terintegrasi satelit berdasarkan GPS. Dilengkapi countdown countdown real-time presisi menuju waktu shalat berikutnya serta simulasi alarm bel pengingat wudhu.

7. **Asmaul Husna**  
   99 Nama Allah Yang Indah lengkap dengan nomor urut, kaligrafi Arab, pelafalan Latin, arti terjemahan, serta bilah pencarian modern beraksen emas.

## 🛠️ Desain & Teknologi

- **Framework**: React 19 + Vite (Single Page Application super cepat & hemat kuota)
- **Bahasa**: TypeScript (Strict Mode Type Safety)
- **Styling**: Tailwind CSS (Desain modern, menenangkan, ramah mata lansia, responsif mobile-first)
- **Animasi**: Micro-interactions dan transisi transparan yang menenangkan jiwa
- **Aset & Ikon**: Lucide Icons (Ikon vektor berkualitas tinggi tanpa gambar eksternal berat)
- **Tema**: Suasana hijau zamrud murni, putih bersih, dengan aksen rasi emas khas ornamen Islami (*Emerald, Green, White, Gold Accent*). Lengkap dengan dukungan Dark Mode!

## 🚀 Cara Menjalankan

1. Instalasi seluruh dependensi pendukung:
   ```bash
   npm install
   ```

2. Jalankan server lokal:
   ```bash
   npm run dev
   ```

3. Buka browser pada alamat:
   `http://localhost:3000`
